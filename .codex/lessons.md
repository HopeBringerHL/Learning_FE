# Shared Lessons

This file is intentionally repository-neutral when first copied.

Store only verified lessons that are useful to future contributors in the current repository.

Preferred format:

## YYYY-MM-DD — Short lesson title

- Context:
- Symptom:
- Verified cause:
- Fix:
- Verification:
- Applies to:

Rules:

- Do not copy lessons from an unrelated repository.
- Do not store temporary debugging transcripts.
- Do not record guesses as facts.
- Do not store secrets, tokens, credentials, personal data, or production data.
- Merge duplicate lessons instead of accumulating conflicting advice.
